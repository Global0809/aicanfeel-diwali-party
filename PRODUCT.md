## Platform

## Purpose

An AICANFEEL Diwali party invitation for 6 November 2026 at 8 PM IST, at DU-131, PitamPura, New Delhi. The visitor experiences the original red HAPE gorilla, scrolls from an extreme close-up to a rotating wide shot, then clicks Yayyyy to reveal the invitation amid fireworks.

## Confirmed requirements

- Preserve the original gorilla, outfit, fonts and red design language.
- Add an actual thick gold chain with raised Diwali Party lettering.
- Use smart, funny and thoughtful short English copy.
- Remove name entry, calendar, directions and hamburger navigation.
- End with a single Yayyyy reveal, fireworks and a hovering invitation pass.
- Optimize for phones and honor reduced motion.
- Publish publicly on GitHub Pages.

## Boundaries

No RSVP backend, personal guest database, admission code or unconfirmed end time. Keep the date, host and venue. This revision leaves the earlier Sites publication unchanged; its new public delivery is on GitHub Pages.
